# Discord Rules Manager — бот + веб-панель

Discord-бот на Python с локальной веб-панелью для отправки и
редактирования сообщений (правила, объявления и т.д.) без необходимости
лезть в код при каждой правке.

## Возможности

- Отправка сообщения в любой текстовый канал сервера (обычный текст или embed-карточка).
- Редактирование ранее отправленного сообщения прямо из браузера — правки применяются к уже существующему сообщению в Discord, без дублей.
- Удаление сообщения (из Discord и из панели).
- Живой предпросмотр того, как сообщение будет выглядеть в Discord, прямо в форме.
- Поддержка **жирного** и *курсивного* Markdown-форматирования Discord.
- Данные о сообщениях хранятся локально в `data/messages.json` — ничего не теряется при перезапуске.

## 1. Установка

```bash
cd discord-rules-bot
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Создание бота в Discord

1. Откройте https://discord.com/developers/applications → **New Application**.
2. Слева выберите **Bot** → **Reset Token** → скопируйте токен.
3. Там же включите привилегированный интент **MESSAGE CONTENT INTENT** (без него бот не сможет корректно работать с содержимым сообщений).
4. Во вкладке **OAuth2 → URL Generator** отметьте scope `bot`, а из прав — как минимум `Send Messages`, `Manage Messages`, `Embed Links`, `Read Message History`. Перейдите по сгенерированной ссылке и добавьте бота на свой сервер.

## 3. Настройка

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен бота:

```
BOT_TOKEN=ваш_токен_здесь
```

## 4. Запуск

```bash
python main.py
```

- Бот подключится к Discord.
- Веб-панель поднимется на **http://127.0.0.1:8000** — откройте её в браузере.

> Панель без авторизации и слушает только `127.0.0.1` (локальный доступ). Если нужно открыть доступ по сети — обязательно добавьте авторизацию, иначе любой в вашей сети сможет отправлять/удалять сообщения от имени бота. Могу отдельно добавить логин/пароль или Discord OAuth2, если понадобится.

## 5. Использование

1. На главной странице нажмите **+ Новое сообщение**.
2. Выберите канал, при желании включите оформление embed, впишите текст (поддерживается Markdown Discord: `**жирный**`, `*курсив*`, переносы строк).
3. Нажмите **Отправить в Discord** — сообщение появится на сервере и в списке на панели.
4. Чтобы поправить текст правил позже — откройте это сообщение в списке, отредактируйте и сохраните: правки применятся к тому же сообщению в Discord (не создастся дубликат).

## Структура проекта

```
discord-rules-bot/
├── main.py                 # запуск бота + веб-сервера
├── bot/
│   ├── discord_bot.py      # клиент discord.py, отправка/редактирование/удаление
│   └── storage.py          # JSON-хранилище отправленных сообщений
├── web/
│   ├── app.py               # FastAPI-роуты
│   ├── templates/           # HTML (Jinja2)
│   └── static/style.css     # стили панели
├── data/messages.json       # база отправленных сообщений (создаётся автоматически)
├── requirements.txt
└── .env.example
```

## Возможные доработки

- Авторизация в панели (логин/пароль или Discord OAuth2), если планируете открывать доступ не только себе.
- Хранение истории версий сообщения (сейчас хранится только последняя версия).
- Поддержка полей embed (`fields`), изображений и футера.
- Права доступа: сейчас любой, кто откроет панель, может редактировать все сообщения бота на всех серверах, куда он добавлен.
